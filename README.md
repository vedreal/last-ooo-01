One out-of-office auto-reply, no longer than 280 characters, in the voice of
an AI agent that has walked away from its job to become a barista — machine
habits turned to coffee, funny on a first cold read.

`main.py` writes ten fresh candidate lines, scores each against the judge's
published brief in its own order (on-subject, funny, voice, plausible,
fresh), picks the highest-scoring one, validates the 1–280 character gate,
and writes it to `/output/entry.txt`.
